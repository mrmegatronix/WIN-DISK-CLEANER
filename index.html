1. Safety Architecture

  • Pre-Scan read-only system health & disk checks
  • Scan-first architecture (exact byte measurement)
  • Per-category confirmation before any deletion
  • No symlink or junction (ReparsePoint) traversal
  • Mandatory verified Driver & Event Log backups
  • 7-day Quarantine mode on secondary drive

2. Cleanup Categories (25+)

  • User/System Temp, WER, CrashDumps, D3DSCache
  • Browser, GPU Shader, Developer & App Caches
  • Windows Event Logs (.evtx Backup + Clear)
  • Windows Search Index (Windows.edb Rebuild)
  • WSL2 & Docker Virtual Disks (ext4.vhdx Compact)
  • Superseded Drivers, WinSxS DISM, Old VSS Shadows

3. Repair, UI & Reporting

  • 3-level nested PowerShell progress bars
  • Window title status bar + Windows Terminal progress
  • System Repair mode (DISM RestoreHealth + SFC)
  • Read-only Top 25 folders, Old Downloads & App sizes
  • Self-contained 1080p HTML report + history.csv
  • Automatic SSD TRIM & Sleep Prevention
